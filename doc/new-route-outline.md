# 第三路线剧情大纲（参考稿）

本稿只作为新路线设计参考，不改变白志超路线、娜塔莉雅路线或原始关卡逻辑。地图优先复用原有 1--168 关；阶段编号以 `json/ref` 的导出结果为索引，真正接入前仍需逐关核对原事件、资源和存档边界。

## 序章：两条道路的交会（140）

- 白志超从迦納国出发，调查北方军队异常调动。
- 娜塔莉雅从奚族部落出发，追查失控魔法和失踪使者。
- 两人在前方短暂相遇，各自介绍身份后决定共同调查，但不强行合并原存档角色。
- 玩家可选择白志超、娜塔莉雅，或第三项共同出发；第三项只记录新路线旗标。

## 第一幕：各自取证（1--30、71--90）

- 白志超调查军需、边境关卡和北方密使的行动记录。
- 娜塔莉雅调查奚族遗迹、魔法污染和被篡改的部落盟约。
- 各组关卡只增加调查旗标，不改变原胜败条件、奖励和路线结算。

## 第二幕：线索汇合（31--60、91--120）

- 两人的线索指向同一批伪造命令和跨境运输线。
- 复用原地图安排短对白、护送、夺取文件和撤离事件。
- 两队可先后抵达同一地点，后一队通过对白得知前一队留下的记号。

## 第三幕：北方密使（61--100）

- 两位主角分别破解敌方假情报网络，确认战争由内部势力推动。
- 白志超负责正面突破和保护使者；娜塔莉雅负责解除结界、辨认真伪情报。
- 新内容只挂在战斗结束后的事件中，保留原战斗目标和奖励流程。

## 第四幕：共同远征（101--135）

- 两位主角组成临时联合队，出战角色仍按原存档规则选择。
- 先解决边境冲突、奚族争端和北方军队补给，再追踪幕后首领。
- 不直接授予等级、装备或技能，成长仍由原战斗与奖励流程处理。

## 终幕：共同的答案（136--168）

- 136--139 检查两位主角的调查旗标和关键伙伴状态。
- 140 只作为第三路线入口，不重复触发两条原路线开场选择。
- 141--150 处理伪造命令源头；151--160 处理最终战场与撤离分支。
- 161--168 保留原结局展示、奖励和存档边界，新增对白挂在原结局完成事件之后。
- 真结局条件为两位主角均完成调查、关键使者存活且最终战胜利；否则按原路线或失败结局收束。

## 实施约束

1. `json/ref/stage-1.json` 至 `stage-168.json` 仅供查阅和比对，不由运行时读取。
2. 运行时 JSON 覆盖只保留源码目录的 `json/stage-140.json`；两条原有路线继续使用 BIN 和原事件逻辑。
3. 每个新增事件必须提供汇编地址、原资源来源、旗标消耗顺序和局部回归证据。
4. 不使用占位角色、未知 CEL 编号、猜测坐标或未经核实的奖励。
